# CaDS Rust Tutor — Docs

<p class="tagline">A browser IDE for learning Rust: the toolchain, the exercises and the course tutor run in a container. No board, no local install, nothing to configure.</p>

You open one link and get VS Code with a prepared Rust workspace and a tutor beside your
editor. It walks you through 31 steps in eight modules, runs the real `cargo` commands for you,
checks your work against the compiler's actual output, and asks you to explain what you did
before it marks a step as understood.

The Rust track needs no hardware. Everything happens inside the container.

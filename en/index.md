# Firmware Lab — Docs

<p class="tagline">One sentence: a browser-only IDE with a real ST-Link connection to real STM32 hardware, and an AI tutor sitting next to your code that explains exactly what each register write does and answers your questions about it — nothing to install.</p>

If you've never touched a microcontroller before, that's exactly who this is for. You open a URL,
you get a working editor, a terminal, and a step-by-step walkthrough that turns on a real LED on a
real chip by writing to real memory addresses — and at every step you can ask the built-in tutor
*why*, in your own words, and get a real answer back.

## What's actually in here

- **Tutorials** — learn by doing, step by step, starting from zero.
- **How-to guides** — a specific task you already know you want to do.
- **Reference** — look up a fact (a keyboard shortcut, a file, a command) without the narrative.
- **Explanation** — understand *why* the system is built the way it is.

This is the [Diátaxis](https://diataxis.fr) documentation framework — if you're not sure where to
look, start with Tutorials.

## Every screenshot in this documentation is real

Every screenshot and every described step in this documentation was taken from an actual, live run
of the system — not mocked up, not described from memory. If something here doesn't match what you
see, that's a real bug worth reporting, not a stale screenshot.

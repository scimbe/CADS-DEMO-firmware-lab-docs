# CaDS JavaScript Tutor — Docs

<p class="tagline">A browser IDE for learning JavaScript: Node, the exercises and the course tutor run in a container. No board, no local install, nothing to configure.</p>

You open one link and get VS Code with a prepared JavaScript workspace and a tutor beside your
editor. It walks you through 31 steps in eight modules, runs the real `node --test` commands for
you, checks your work against the runtime's actual output, and asks you to explain what you did
before it marks a step as understood.

No prior programming experience is assumed, and no earlier course is required.
